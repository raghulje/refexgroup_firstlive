# Static Assets - Consolidated

This folder contains all static assets consolidated from:
- public/assets/
- public/svg/
- public/wp-content/

## Structure

```
wp-content/
├── assets/       # Images, icons, logos from public/assets
├── svg/          # SVG files from public/svg
└── uploads/      # Legacy WordPress uploads
```

## Usage

These are legacy static assets kept for reference.
New assets should be uploaded via CMS to server/uploads/

## Note

This folder is version controlled and should only contain
assets that are truly static and rarely change.

For dynamic content (hero images, news articles, etc.),
use the CMS upload feature instead.
